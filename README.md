# 🌐 MAX Desktop Portable

**MAX Desktop Portable** — это кастомный, легковесный и полностью портативный браузер-клиент, созданный на базе Python и PyQt6 (WebEngine). Программа разработана для безопасного и удобного использования веб-приложений с поддержкой мультиаккаунтинга, встроенными инструментами антидетекта и глубокой кастомизацией интерфейса.

---

## ✨ Ключевые возможности

### 🎭 Продвинутый мультиаккаунтинг
* **Изолированные профили:** Каждый добавленный аккаунт имеет собственную папку хранения (`storage_Название`), что гарантирует полное разделение cookie, кэша и локальных данных.
* **Быстрое переключение:** Удобная смена активного профиля прямо из меню настроек "на лету" без перезапуска приложения.

### 🛡 Антидетект и Приватность
* **Подмена отпечатков (Spoofing):** Эмуляция различных устройств и браузеров (например, *Windows 11 Chrome* или *macOS Safari*). Подменяются User-Agent, платформа, видеокарта (Renderer), разрешение экрана и язык.
* **Canvas Noise:** Добавление шума в HTML5 Canvas для предотвращения отслеживания (Fingerprinting).
* **WebRTC Leak Protection:** Блокировка утечки реального IP-адреса через протокол WebRTC.
* **Встроенный AdBlock:** Скрытие рекламных блоков и трекеров на уровне CSS.

### 🎨 Кастомизация интерфейса
* **Встроенные темы:** Стандартная, Темная (в стиле Telegram) и AMOLED Черная.
* **Управление отображением:** Настройка масштаба страниц (80% - 150%) и возможность скрыть полосы прокрутки.
* **Режим "Без звука":** Принудительное отключение аудио для выбранных профилей.

### ⚙️ Удобство использования
* **Портативность:** Программа не требует установки. Все настройки (`config.json`), загрузки и данные профилей хранятся строго в папке с исполняемым файлом.
* **Фоновый режим:** При закрытии приложение сворачивается в системный трей.
* **Умный загрузчик файлов:** Кастомная панель загрузок с отображением прогресса (МБ, проценты) и возможностью отмены. Файлы сохраняются в папку `Downloads`.
* **Офлайн-режим:** Красивая заглушка при потере интернет-соединения с автоматическим восстановлением страницы при появлении сети.

### 🛠 Встроенная диагностика
Генерация детального отчета о системе (ОЗУ, процессор, дисковое пространство, версия ОС) и текущих настройках программы в один клик для быстрой отправки в техподдержку.

## 🚀 Установка и запуск (Для разработчиков)

### Требования
* Python 3.8 или новее
* ОС: Windows, macOS или Linux

### 1. Клонирование и зависимости
Установите необходимые библиотеки с помощью pip:
`pip install PyQt6 PyQt6-WebEngine`

### 2. Запуск исходного кода
`python main.py`
*(где `main.py` — имя файла с кодом)*

---

## 📦 Сборка в `.exe` (Portable версия)

Программа изначально спроектирована для компиляции в один исполняемый файл с помощью **PyInstaller**. В коде уже предусмотрена функция `resource_path` для корректного поиска иконки при распаковке.

Пример команды для сборки:
`pyinstaller --noconfirm --onedir --windowed --icon "max.ico" --add-data "max.ico;."  "main.py"`

---

## 📂 Структура данных приложения

После первого запуска программа автоматически создаст следующие файлы и папки в своей директории:
* `config.json` — глобальные настройки приложения и параметры каждого профиля.
* `storage_{ИмяПрофиля}/` — папки движка Chromium с кэшем, куками и сессиями для каждого аккаунта.
* `Downloads/` — папка для скачанных через приложение файлов.
