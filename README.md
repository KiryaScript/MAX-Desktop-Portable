# ✦ MAX Desktop Portable (Node.js / Electron Edition)

> **Быстрый, приватный и полностью портативный клиент для мессенджера MAX (`web.max.ru`) без слежки, с маскировкой отпечатков, изолированным мультиаккаунтом и нативным десктопным интерфейсом.**

---

## 🌟 Ключевые возможности

- 🚀 **100% Портативность:** Не требует установки. Все данные (кэш, куки, локальные базы, настройки) хранятся исключительно в папке `storage/` рядом с программой. Реестр и системные папки Windows (`AppData`, `Temp`) не засоряются.
- 👥 **Изолированный Мультиаккаунт:** Поддержка неограниченного числа аккаунтов. У каждого профиля своя независимая сессия (партиция), куки, IndexedDB и изолированные настройки маскировки.
- 🛡️ **Максимальная Приватность и Антидетект:**
  - 🚫 **WebRTC Strict Relay:** Принудительная маршрутизация WebRTC только через защищённые relay-серверы для 100% блокировки утечки реального IP-адреса.
  - 🎨 **Шум Canvas & 🔊 AudioContext:** Алгоритмическое внесение неопределимого микро-шума при снятии браузерных отпечатков (Fingerprinting protection).
  - 🎭 **Маскировка Устройств:** Подмена User-Agent, платформы, вендора, параметров экрана под Windows 11 Chrome, macOS Safari, Linux Firefox и др.
  - 🛑 **Встроенный AdBlock:** Блокировка рекламных и трекинговых баннеров на уровне DOM и сети.
  - 🌐 **Индивидуальный Прокси:** Поддержка HTTP / SOCKS5 прокси для каждого профиля.
- 🎨 **Нативный Десктопный Интерфейс:**
  - Никаких браузерных элементов (убраны кнопки «Назад/Вперёд», адресная строка и системные рамки).
  - Элегантный тёмный Frameless-титулбар с векторными SVG-кнопками Windows 10/11.
  - Боковой док быстрого переключения аккаунтов с цветными аватарами.
  - Индикатор сетевого подключения в реальном времени.
- 📥 **Умный Загрузчик Файлов:**
  - Скачивание файлов, голосовых сообщений, медиа и документов прямо внутри приложения в системную папку `Downloads`.
  - Автоматическое определение MIME-типа и расширения файлов (`.jpg`, `.png`, `.mp4`, `.pdf`, `.zip` и т.д.).
  - Всплывающая карточка прогресса с возможностью отмены и уведомлением в системный трей.
  - Внешние веб-ссылки открываются в стандартном браузере ОС.
- 🎥 **Полная Поддержка Медиа:**
  - Аппаратное ускорение видеодекодирования и воспроизведения видеосообщений в чатах.
  - Полноэкранный режим просмотра видео (`allowfullscreen`).
- ⚡ **Совместимость со всеми версиями Windows:**
  - Работает на Windows 10 (от ранних 1507/1607/1809 LTSC, IoT LTSC до современных версий), урезанных/Lite-сборках (Ghost Spectre, CompactOS) и Windows 11 Pro / Enterprise.

## ⌨️ Горячие клавиши

| Сочетание клавиш | Действие |
|---|---|
| `Ctrl + T` | Добавить новый аккаунт |
| `Ctrl + 1` ... `Ctrl + 9` | Быстрое переключение между аккаунтами |
| `Ctrl + Shift + S` | Открыть панель настроек |
| `Ctrl + W` | Свернуть приложение в системный трей |
| `Ctrl + R` / `F5` | Перезагрузить текущий клиент |
| `Ctrl + Колесо мыши` | Масштабирование интерфейса (Zoom In / Zoom Out) |
| `F1` | Справка по горячим клавишам |
| `Escape` | Закрыть любое активное модальное окно |

## 🛠️ Разработка и сборка

### Требования
- **Node.js:** v18.0.0 или новее (рекомендуется v20+)
- **npm:** v9.0.0 или новее

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm start
```

### 3. Сборка портативного исполняемого файла (.exe)
```bash
# Сборка одного автономного Portable файла:
npm run build

# Сборка распакованной директории (для быстрого тестирования):
npm run build:dir
```
После сборки готовый файл будет находиться в директории `dist/MAX-Desktop-Portable.exe`.
